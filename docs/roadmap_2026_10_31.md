하루 약 2~3시간을 가정한 계획이다. 설치 대기는 별도이며, 환경 구축이 이미 완료되어 데이터 준비부터 이어간다.

|---|---|---|
| 10/30 | 환경 구축, GPU 계산 확인, YOLO 예제 1장 검출 | 완료: 로그·결과 캡처 |
| 10/31 | 환경·일지 기록, KITTI 다운로드 및 구성 확인 시작 | 기록 업데이트 / 데이터 확보는 예정 |
| 11/1 | 이미지 10장과 GT 확인, 정답·예측 박스 비교, 클래스 대응 | 예정 |
| 11/2 | 고정 50~100장 정상 평가, 밝기 3단계 생성 | 예정 |

**권장 목표:** 정상 영상 + 밝기 감소 3단계 정량 비교.
**최소 목표:** 실행 환경·검출·열화 생성·비교 그림·평가 설계. 정량 평가 미완료 시 명시한다.
**추가 목표:** Gaussian Blur. Noise·Fog·복합 열화는 제출 이후로 둔다.

11월 2일까지 정상 평가가 동작하지 않으면 열화 종류 추가를 멈추고 라벨·클래스·평가 오류 해결에 집중한다.
보고서가 10월 활동만을 대상으로 하면 11월 수행 결과를 소급하지 않고 별도 추가 진행으로 구분한다.
