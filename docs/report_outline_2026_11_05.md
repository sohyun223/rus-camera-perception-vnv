# 11/5 보고서 내용·사진 구성안

9월 학부생 활동보고서의 기본정보 → 연구주제/진행사항 → 활동사진 4장 → 월별 의견 → 서명 구성을 따른다. 본 파일은 구성안이며 제출·서명 완료 문서가 아니다.

## 진행사항 구성

1. 연구 방향 변경 및 Ubuntu/GPU·KITTI·YOLO11n 실험 환경.
2. 고정 100장의 원본 정밀도·재현율 평가. 자동차 Recall 69.47%, 보행자 56.41%.
3. 원본+밝기/Blur/Noise 각 3단계의 10조건 평가 및 GT별 실패 사례 분석.
4. JSON 설정 기반 통합 실행, 집계 20/20행 일치, 잠정 기준 자동 판정(PASS 6/FAIL 3).
5. Noise 25·22 탐색과 제한적 해석, 멘토 검토 후 기준 확정 및 독립 본 평가 계획.

Noise 22 보행자는 Recall 50.00%, 유지율 88.64%로 미달했다. 잠정 기준을 최종 안전 기준 또는 정확한 최대 허용 Noise로 표현하지 않는다. mAP·Fog·복합 열화·CI 완료로 적지 않는다.

## 활동사진 4장 추천

| 칸 | 자료 | 캡션 예시 |
|---|---|---|
| 1 | KITTI 원본의 정답/YOLO 검출 비교 | KITTI 정답 바운딩박스와 YOLO11n 검출 결과 비교 |
| 2 | 열화 강도별 재현율 그래프 | 영상 열화 강도에 따른 클래스별 재현율 변화 |
| 3 | 같은 장면의 원본/Noise 30 실패 비교 | 잡음 적용 후 정답 물체의 TP→FN 전환 사례 |
| 4 | 기존 10조건 자동 판정 출력 | 잠정 재현율 유지 기준에 따른 자동 판정 결과 |

새 비교 사진과 통합 그래프 원본은 이번 원격 업데이트에서 직접 받지 않았다. 2번에 밝기 그래프만 사용하면 캡션도 밝기 실험으로 한정한다. 백업 화면이나 코드 화면보다 결과가 명확한 사진을 우선한다.

보고 기간이 10월로 한정되면 11월 수행 내용은 추가 진행으로 구분한다. 연구활동 의견에는 정답 기반 정량 평가, 반복 실험, 기준 기반 판정을 통해 배운 점을 쓴다.
